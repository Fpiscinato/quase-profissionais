# Os Quase Profissionais

Tennis Americano Manager — static PWA, no backend. See `SPEC.md` for the
authoritative spec (read it first).

## Dev

```sh
npm install
npm run dev
npm run test    # unit tests (engine)
npm run build   # typecheck + production build
```
